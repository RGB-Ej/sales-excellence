# Sales Excellence

A sales CRM for running a B2B pipeline in the MENA region, built to replace Excel.

## Features

- **Today**: follow-ups due, tasks, deal next steps, weekly call and meeting targets
- **Pipeline**: board, table, review and insights, with MEDDICC qualification on every deal
- **Week plan**: Sunday to Thursday work week, plus the **Weekly report** (last week's review and this week's plan) with history and Excel (.xlsx) export
- **Calls**: call queue, a daily call list that tops itself up (focus countries and priority titles), quick logging, and tap-to-call that opens the Maqsam dialer
- **Reach**: one button per contact for call, WhatsApp, email (opens Outlook) and LinkedIn
- **Contacts and Accounts**: owner per lead (you or an SDR), lists, account timeline and notes
- **Cadences**: multi-touch sequences that turn into dated tasks
- **SDR team**: calls, connect rate, meetings booked and pipeline per SDR
- **Import and export**: Excel or CSV import with column matching; CSV and Excel export

## Run it

It is a single `index.html` file with no build step. Open it in a browser, or publish it with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

## Where the data lives

In this version, data is saved in the browser on each device. Use **Settings → Download backup** to keep a copy, and **Restore** to move data to another device.

The version hosted inside Claude adds cloud sync across devices, shared access for SDRs, the AI coach (drafts, call prep, company info, voice-note scripts) and Apollo import.
